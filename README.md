# SMM-ассистент с ИИ для блога о путешествиях

**Telegram-бот для автоматизации генерации контента, планирования публикаций и аналитики.**

---

## 📌 О проекте

Проект разработан для автоматизации SMM-процессов в блогах о путешествиях. Бот использует искусственный интеллект (GPT-4, DALL·E) для создания текстов и изображений, интегрируется с Telegram и сервисами автоматизации (Albato). Решение позволяет:
- Генерировать креативные посты.
- Планировать публикации.
- Собирать аналитику вовлеченности (в разработке).

---

## 🛠 Технологический стек

- **Языки и фреймворки:** Python, Aiogram (Telegram API).
- **AI-инструменты:** OpenAI API (GPT-4, DALL·E).
- **Интеграции:** Albato, Gmail, Google Cloud.
- **Сервер:** PythonAnywhere (облачное развертывание).
- **База данных:** Локальное хранение данных (SQLite в перспективе).

---

## 🚀 Реализованные функции

### Для пользователей:
- Генерация текстов и изображений по команде `/generate`.
- Планирование публикаций (до 30 дней).
- Сохранение контента в Gmail и на сервере.

### Для администраторов:
- Настройка ID Telegram-группы через `/set_group`.
- Управление расписанием (`/set_schedule`).
- Уведомления об ошибках и успешных отправках.

---

## ⚠️ Известные ограничения (версия MVP)
- Нестабильная работа при высокой нагрузке.
- Отсутствие дашборда для аналитики.
- Частичная интеграция с Albato.
- Ограничение на длину текста (4000 символов).

## 🛠 Установка и запуск

### Требования:
- Python 3.10+
- API-ключи: OpenAI, Telegram.

### Инструкция:
1. Клонируйте репозиторий:
   git clone https://github.com/your-repo/smm-ai-assistant.git
2. Установите зависимости:
   pip install -r requirements.txt
3. Настройте переменные окружения в .env:
  TELEGRAM_TOKEN=your_token
  OPENAI_API_KEY=your_key
4. Запустите бота:
  python bot.py
